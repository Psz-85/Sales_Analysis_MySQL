# Sales Analysis - MySQL

## Opis projektu

Projekt przedstawia analizę sprzedaży z wykorzystaniem relacyjnej bazy danych MySQL.

Celem projektu było zaprojektowanie bazy danych, utworzenie relacji pomiędzy tabelami oraz wykonanie analiz biznesowych przy użyciu języka SQL.

## Wykorzystane technologie

- MySQL
- SQL
- phpMyAdmin
- GitHub

## Struktura bazy danych

Projekt składa się z czterech tabel:

- customers
- products
- orders
- order_items

Relacje zostały utworzone przy pomocy kluczy głównych (PRIMARY KEY) oraz kluczy obcych (FOREIGN KEY).

## Przykładowe analizy

- analiza najlepiej sprzedających się produktów,
- analiza produktów generujących najwyższy przychód,
- analiza najbardziej wartościowych klientów,
- analiza statusów zamówień,
- analiza średniej wartości zamówienia.

## Umiejętności SQL wykorzystane w projekcie

- CREATE DATABASE
- CREATE TABLE
- PRIMARY KEY
- FOREIGN KEY
- INSERT INTO
- INNER JOIN
- GROUP BY
- ORDER BY
- SUM()
- COUNT()
- AVG()
